# Assignment 4: Critical Analysis of ML Papers in Health

In this assignment, each group will read and critically analyze one machine learning paper applied to health data. All papers follow a classical ML pipeline: feature extraction from clinical or physiological data, followed by a traditional classifier — the same approach covered throughout this course.

**First step:** choose your paper using the **Choice activity** on this page. Maximum 2 groups per paper — first come, first served. The list of papers with links is available in the attached PDF.

---

## What to Submit

A single **PDF, max 3 pages**, including the following four sections:

1. **Pipeline diagram.** Draw the full ML workflow of the paper: data source → preprocessing → feature extraction → model → evaluation. This is the most important part of the report.
2. **Dataset and problem.** What clinical problem are the authors solving? Describe the dataset: source, size, key features, and any notable challenges such as missing data or class imbalance.
3. **One thing you would do differently.** If you had access to this dataset, what would you change about the method or evaluation? Your suggestion must explicitly connect to a topic covered in the course.
4. **Clinical deployment critique.** What are the risks of using this model in a real clinical setting? Identify one potential bias or generalization concern specific to health data.
